# AOS E-Commerce Application – Manual QA Testing Project

## Project Overview

This project showcases my hands-on experience in **Manual Software Quality Assurance Testing** using the Advantage Online Shopping (AOS) e-commerce application.

The purpose of this project was to evaluate application functionality, identify software defects, validate expected versus actual results, and document testing activities using structured QA methodologies.

The project demonstrates my ability to design and execute test cases, report reproducible defects, and communicate testing findings.

## Testing Objectives

- Verify that core e-commerce features function according to expected requirements.
- Validate user authentication and account registration.
- Test product search, filtering, and product specifications.
- Verify shopping cart and checkout functionality.
- Evaluate the handling and display of payment information.
- Identify usability and navigation defects.
- Document and communicate defects with clear reproduction steps.

## Scope of Testing

### 1. User Authentication and Account Management
- Valid login credentials
- Invalid login credentials
- Empty login fields
- Account registration and mandatory fields
- Forgot Password functionality

### 2. Product Search and Product Information
- Product search using full and partial keywords
- Product filtering
- Product details and specifications
- Special offers and promotional information

### 3. Shopping Cart and Checkout
- Adding products to the shopping cart
- Reviewing cart information
- Shipping and address information
- Checkout workflow
- Saved payment information and CVV display

### 4. Navigation and Usability
- Website navigation
- Product information accuracy
- Social media links
- Error messages and user feedback

1. **Test Planning:** Identified the testing scope, objectives, and functional areas.

4. **Defect Reporting:** Documented failures using structured Jira-style bug reports.
5. **Test Reporting:** Summarized test execution results, identified defects, and testing observations.
