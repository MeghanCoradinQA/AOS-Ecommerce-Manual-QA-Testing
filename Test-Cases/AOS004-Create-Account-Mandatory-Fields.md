# AOS004 – Create Account (Mandatory Fields)

## Test Case Information

| Field | Details |
|---|---|
| Test Case ID | AOS004 |
| Module | User Registration / Account Management |
| Test Type | Functional / Positive Testing |
| Priority | High |
| Execution Status | Not Confirmed |

## Test Objective

Verify that a new user can successfully create an account in the Advantage Online Shopping (AOS) application by completing all mandatory registration fields with valid information.

## Preconditions

- The AOS application is accessible.
- The user is not logged in.
- The registration page is available.
- A unique username and email address are available for testing.

## Test Data

- Username: Unique test username
- Email: Valid test email address
- Password: Valid password meeting application requirements
- Confirm Password: Matching password
- Other mandatory fields: Valid test information

Do not include real passwords or personal information in the public repository.

## Test Steps

| Step | Test Action | Expected Result |
|---|---|---|
| 1 | Navigate to the AOS website | Homepage loads successfully |
| 2 | Click the user/account icon | Login window appears |
| 3 | Select Create New Account | Registration form opens |
| 4 | Identify all mandatory registration fields | Required fields are clearly indicated |
| 5 | Enter valid information in all mandatory fields | Information is accepted |
| 6 | Confirm the password and complete any required acknowledgments | Required inputs are completed |
| 7 | Click Register | Account is created successfully |

## Expected Result

The application should accept valid information in all mandatory fields, successfully register the new user, and provide appropriate confirmation or account access.
